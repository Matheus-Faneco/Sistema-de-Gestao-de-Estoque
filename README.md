# Sistema de Gestão de Estoque - MostraTECH FPF Tech
Demo da aplicação: https://cutt.ly/ZeXjUQcM **(Apenas Frontend)**

## Descrição

Este projeto é um sistema web completo para gestão de estoque, desenvolvido como parte da segunda MostraTECH da Escola Tecnológica da FPF Tech. A aplicação permite o cadastro e gerenciamento de produtos, categorias, marcas, fornecedores, além de controlar entradas e saídas de produtos através de dashboard.

## Tecnologias Utilizadas

* **Frontend:** Angular

* **Backend:** Django

* **Banco de dados:** PostgreSQL

## Funcionalidades

* **Dashboard:**
    * Visão geral em tempo real das entradas e saídas de produtos em um determinado período.
* **Produtos:**
    * Cadastro detalhado de produtos, incluindo nome, descrição, categoria, marca, fornecedor e quantidade em estoque.
    * Listagem completa de todos os produtos cadastrados.
* **Categorias, Marcas e Fornecedores:**
    * Cadastro e listagem de categorias, marcas e fornecedores, com a mesma lógica das funcionalidades de produtos.
* **Entradas e Saídas:**
    * Registro detalhado das entradas e saídas de produtos, com data, quantidade e observações.
